# Maxwell Education

Maxwell Education is a tutoring and academic preparation provider based in **Richmond Hill, Ontario, Canada**, serving students in **Grades 3–12** through **in-person and online instruction**.

The academy focuses on **Math, Science, Programming, advanced academic coursework, and academic competition preparation**.

## What Maxwell Education Is

Maxwell Education provides long-term academic support for students from elementary through high school.

Students may join Maxwell Education at different grade levels and do not follow one fixed curriculum. Their subjects, course levels, and academic goals may change as they progress.

The central model is called the **One Continuous Track**.

## One Continuous Track

**One Continuous Track is Maxwell Education's long-term academic progression model for students across Grades 3–12.**

It describes continuity of academic development rather than a single fixed curriculum.

Students are not required to:

* start at Grade 3;
* take every subject offered by Maxwell;
* follow the same course sequence;
* participate in competitions;
* take AP or IB courses; or
* remain in one identical program throughout Grades 3–12.

Instead, students may enter Maxwell at different stages and develop through different combinations of Math, Science, Programming, advanced coursework, and competition preparation according to their academic level and goals.

The word **"continuous"** refers to the ability to support a student's academic progression over multiple grade levels, from foundational learning through increasingly advanced coursework and university preparation.

## Academic Progression

The general progression can be understood as:

**Grades 3–8 → Foundations**

Students develop strong fundamentals in areas such as mathematics, science, and programming. The emphasis is on conceptual understanding, fluency, problem solving, and closing important academic gaps.

**Grades 9–12 → Higher Horizons**

Higher Horizons is Maxwell Education's **Grades 9–12 pathway within the One Continuous Track**.

It connects advanced coursework, course planning, AP/IB preparation, academic competitions, and university-level academic readiness.

Higher Horizons is therefore not a separate alternative to the One Continuous Track. It represents the Grades 9–12 stage of that broader progression model.

# Maxwell Education — Website

A Vite + React + Tailwind CSS project, set up to auto-deploy to **GitHub
Pages** every time you push to `main`.

## 1. Run it locally (optional, to preview before publishing)

```bash
npm install
npm run dev
```

## 2. Before you publish — 2 things to replace

- **Certificate images**: `public/assets/credentials/*.svg` are placeholders.
  Replace each file with the real scanned certificate (keep the same
  filename, or update the `image:` paths in `src/App.jsx` inside the
  `CredentialsWall` component).
- **Domain in structured data**: `src/App.jsx` has a `SCHEMA_ORG_JSONLD`
  object near the top using `maxwelleducation.example` as a placeholder.
  Once GitHub Pages gives you a real URL (step 4 below), swap it in here.

## 3. Push to GitHub

Create a new **public** repository on GitHub first (empty, no README), then:

```bash
git init
git add .
git commit -m "Initial site"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```

## 4. Turn on GitHub Pages (one-time setup)

1. On GitHub, open your repo → **Settings** → **Pages** (left sidebar).
2. Under "Build and deployment" → **Source**, choose **GitHub Actions**.
3. That's it — don't pick a branch/folder option, the workflow handles it.

The moment you pushed in step 3, the workflow in
`.github/workflows/deploy.yml` already ran automatically (check the
**Actions** tab on GitHub to watch it build). Once it finishes and Pages
is turned on, your site is live at:

```
https://<your-username>.github.io/<your-repo>/
```

(If you name the repo exactly `<your-username>.github.io`, it's served at
the root instead: `https://<your-username>.github.io/` — the workflow
detects this automatically, no config changes needed either way.)

## 5. Every future update

Just commit and push to `main` — the workflow rebuilds and redeploys
automatically. Nothing else to run.

```bash
git add .
git commit -m "Update site"
git push
```

## Troubleshooting

- **Actions tab shows a red ❌**: click into the failed run to see the
  error — usually a typo introduced while editing `src/App.jsx`.
- **Page loads but with no styling**: hard-refresh (styles are
  cache-busted per deploy, but browsers can be stubborn). If it persists,
  check that the Pages source is set to "GitHub Actions" and not "Deploy
  from a branch".
- **Custom domain**: Settings → Pages → "Custom domain" — GitHub gives
  you the DNS records to add at your domain registrar.
